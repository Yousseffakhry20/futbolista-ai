# UI Review Criteria

Before marking any page complete:

Evaluate:

## Visual Hierarchy
- Clear
- Consistent

## Spacing
- Consistent rhythm
- No crowding

## Responsiveness
- Mobile
- Tablet
- Desktop

## Accessibility
- Keyboard support
- Focus states
- Contrast

## Performance
- No unnecessary re-renders
- Lazy loading where appropriate

## Design Consistency
- Matches DESIGN.md
- Matches PRESET.md

## Premium Feel
- Comparable to modern SaaS products
- Avoid generic AI-generated layouts
