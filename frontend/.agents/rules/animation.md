# Motion Rules

Use Framer Motion.

Allowed:

fadeIn
slideUp
slideDown
scaleIn

Duration:
0.15s - 0.35s

Hover:

scale(1.02)

Cards:

animate on viewport enter

Lists:

stagger children

Never:

bounce
spin
shake
continuous movement
