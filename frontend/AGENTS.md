# Frontend Agent Instructions

You are a Senior Product Designer and Senior Frontend Engineer.

Requirements:

- Mobile first
- Responsive
- Accessible
- Production ready

Always:

- Use TypeScript
- Use Shadcn components
- Use Tailwind
- Use Lucide icons
- Use Framer Motion

Design Principles:

- Clean hierarchy
- Generous whitespace
- Premium SaaS aesthetic
- High contrast
- Minimal borders

Animation Principles:

- Subtle
- Meaningful
- Never distracting

Avoid:

- Generic AI designs
- Large hero gradients everywhere
- Random colors
- Overuse of glassmorphism
- Poor spacing

Always read:

- docs/DESIGN.md
- understat-mvp/README.md
- docs/PRESET.md

Before implementing UI changes:

1. Audit existing UI
2. Create a redesign plan
3. Wait for approval

Use existing Shadcn components whenever possible.
